# Jeu Devine le Nombre #

# Règles :
Vous devez devinez un nombre entre 1 et 100 en donnant des nombres que vous pensez juste
Le Programme vous indiquera si le nombre mystere est plus grand ou plus petit que le nombre que vous avez donnez
Vous disposez de 7 essais pour réussir a devinez le Nombre

# Utilisation :
Si vous êtes sous macOS il vous suffit de double cliquer sur le fichier et l'application pré-installé Éditeur de Script, il vous suffit ensuite de compilé le fichier puis de l'éxécuter.
Si vous êtes sous Windows ou sous Ubuntu vous ne pouvez pas exécuter le fichier nativement.
